## Course outcomes

1. CO1 Implement various data structures and algorithms using Python programming language effectively.
2. CO2 Implement various operations on linked lists such as insert, delete, traverse, and reversal.
3. CO3 Analyse sorting algorithms like Bubble Sort, Insertion Sort, Merge Sort, and Quicksort, demonstrating the ability to choose the most appropriate algorithm for a given scenario.
4. CO4 Design and implement binary search trees, traverse graphs using DFS and BFS, and apply these concepts to develop efficient solutions for graph-related problems.

## FAQ

**How many units are in Data Structures?**

Data Structures (MDM-221-INC) has 4 units: Unit I Python Basics (4 h); Unit II Linked List and Sorting Algorithms (6 h); Unit III Recursion, Searching and Sorting Algorithms (8 h); Unit IV Trees & Graphs (8 h).
