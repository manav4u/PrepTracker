UNIT IV

### Transaction Management and Concurrency Control

8 hours

Derived reading outline. Source text split at semicolons, line breaks and sentence boundaries, not an official topic hierarchy.

## Course outcomes

1. CO1 Explain the fundamental concepts, architecture, and functionalities of database management systems.
2. CO2 Analyze and design relational database (RDBMS) model to represent real-world database applications and demonstrate RDBMS principles.
3. CO3 Improve the database design through normalization.
4. CO4 Formulate database queries using SQL and PL/SQL for efficient data retrieval and manipulation.
5. CO5 Demonstrate ACID properties for transaction management and describe concurrency control protocols.
6. CO6 Explore and discuss recent trends in database technologies.

## FAQ

**How many units are in Database Management System?**

Database Management System (PCC-251-ITT) has 5 units: Unit I Introduction to Database Management System (8 h); Unit II Relational Model and Database Design (8 h); Unit III Structured Query Language (SQL) & Procedural SQL (PL/SQL) (8 h); Unit IV Transaction Management and Concurrency Control (8 h); Unit V Emerging Trends in Database Technologies (6 h).

**What is the marks scheme for Database Management System?**

The official Information Technology 2024 pattern syllabus lists continuous comprehensive evaluation (CCE) for 30 marks and the end-semester exam for 70 marks, for 3 credits.

**What should I know before Database Management System?**

Prerequisite listed in the syllabus: Data Structures & Algorithms.
