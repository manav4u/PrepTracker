## Course outcomes

1. CO1 Explain the basic principles, terminologies, classifications of control systems, and develop mathematical models of physical systems using transfer function approach.
2. CO2 Analyse the time-domain response of control systems and evaluate performance indices such as rise time, settling time, peak time, delay time, overshoot and steady-state error.
3. CO3 Determine the stability of control systems using analytical methods and construct and interpret root locus plots to assess system behaviour.
4. CO4 Analyse the control system in the frequency domain using Bode plot to assess stability and robustness.
5. CO5 Design and tune PID controllers to meet desired performance specifications in time-domain Determine transfer functions of lead and lag compensator networks.

## FAQ

**How many units are in Control System Engineering?**

Control System Engineering (PCC-352-ELE) has 5 units: Unit I Basics of Control System (8 h); Unit II Time-Domain Analysis (8 h); Unit III Stability Analysis and Root Locus (8 h); Unit IV Frequency Domain Analysis (8 h); Unit V Design of PID Controller (8 h).

**What is the marks scheme for Control System Engineering?**

The official Electrical Engineering 2024 pattern syllabus lists continuous comprehensive evaluation (CCE) for 30 marks and the end-semester exam for 70 marks, for 3 credits.

**What should I know before Control System Engineering?**

Prerequisite listed in the syllabus: Laplace Transform, ordinary differential equations.
