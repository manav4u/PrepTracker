Unit-wise syllabus

UNIT I

Fundamentals of Cloud Computing

9 hours

Introduction to Cloud Computing, Need and Evolution of Cloud Computing, Characteristics of Cloud Computing, Advantages and Limitations, Cloud Service Models: IaaS, PaaS, SaaS, Cloud Deployment Models: Public, Private, Hybrid, Community Cloud, Cloud Architecture, Cloud Storage and Data Management, Overview of Cloud Providers.

Case Study : Migration of a College ERP System to Cloud

UNIT II

Virtualization and Containerization

9 hours

Introduction to Virtualization, Benefits and Applications of Virtualization, Types of Virtualization, Hypervisors: Type-I and Type-II, Virtual Machines, Introduction to Containers, Docker Fundamentals, Comparison of Virtual Machines and Containers, Basic Container Deployment, Introduction to Kubernetes.

Case Study : VMware and Docker in Enterprise Computing

UNIT III

Cloud Platforms and Services

9 hours

Introduction to AWS, Amazon EC2 and S3 Concepts, Introduction to Microsoft Azure, Azure Virtual Machines and Storage, Google Cloud Platform Overview, Open-Source Cloud Platforms, Cloud Databases, Cloud-Based Application Deployment, Cloud Services for AI, IoT and Data Analytics

Case Study : Cloud Services Used in Google Workspace.

UNIT IV

Cloud Security and Risk Management

9 hours

Introduction to Cloud Security, Security Challenges in Cloud Computing, Data Security and Privacy, Identity and Access Management, Authentication and Authorization, Cloud Threats and Vulnerabilities, Risk Management Process, Business Continuity and Disaster Recovery, Security Best Practices, Compliance and Governance Basics.

Case Study : Analysis of a Cloud Data Breach Incident

UNIT V

Modern Cloud Environment and Emerging Technologies

9 hours

Edge Computing and Fog Computing, Serverless Computing, DevOps and Cloud, Continuous Integration and Continuous Deployment (CI/CD), Infrastructure as Code, Green Cloud Computing, Multi-Cloud and Hybrid Cloud, AI and Machine Learning in Cloud, Future Trends in Cloud Computing.

Case Study : Cloud Adoption Journey of Netflix

Course outcomes

  1. CO1To explain the concepts, characteristics, architectures, and service models of cloud computing.
  2. CO2To demonstrate virtualization and containerization technologies used for cloud infrastructure and application deployment.
  3. CO3To deploy and manage applications, storage, and services using cloud computing platforms.
  4. CO4To analyze modern cloud technologies, DevOps practices, and emerging trends in cloud computing.

FAQ

How many units are in Cloud Computing?

Cloud Computing (PEC-321A-IT) has 5 units and 45 hours of theory: Unit I Fundamentals of Cloud Computing (9 h); Unit II Virtualization and Containerization (9 h); Unit III Cloud Platforms and Services (9 h); Unit IV Cloud Security and Risk Management (9 h); Unit V Modern Cloud Environment and Emerging Technologies (9 h).

What is the marks scheme for Cloud Computing?

The official Information Technology 2024 pattern syllabus lists continuous comprehensive evaluation (CCE) for 30 marks and the end-semester exam for 70 marks, for 3 credits.

What should I know before Cloud Computing?

Prerequisite listed in the syllabus: Computer Networks.
