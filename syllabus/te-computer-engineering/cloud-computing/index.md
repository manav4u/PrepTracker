UNIT III

### Cloud Platforms and Applications

9 hours

Derived reading outline. Source text split at semicolons, line breaks and sentence boundaries, not an official topic hierarchy.

- Industrial Cloud Platforms: Amazon Web Services (AWS)- AWS infrastructure, Components, Amazon Simple DB, Elastic Cloud Computing (EC2), Amazon Storage System, Amazon Database Services.
- Microsoft Azure: Azure core concepts, SQL Azure, and Application Services for managed runtimes.
- Open Source Platforms: Overview of OpenStack, CloudStack, and Eucalyptus for private cloud deployment.
- Cloud Applications: Data-Intensive & Emerging Applications: Smart Cities & IoT: Integrating sensor data from traffic, waste management, and power grids into a centralized cloud dashboard.
- AI/ML in the Cloud: Case study on Google Photos (image recognition) or Alexa (Natural Language Processing) using cloud-based TPU/GPU instances.
- Healthcare & Biology: Gene sequencing, protein folding and ECG analysis in the cloud.
- Geoscience: Satellite image processing and seismic data analysis using cloud clusters.
- Case Study: The Google Case Study Data Processing: The evolution from MapReduce to Dremel and BigQuery.
- Storage Innovation: Understanding the Google File System (GFS) and BigTable as the backbone of global search.

## Course outcomes

1. CO1 Comprehend basic concepts of cloud computing environment •
2. CO2 Analyze Virtualization for cloud and install Virtualization software •
3. CO3 Configure, Test and Deploy applications on Cloud •
4. CO4 Understand and Apply security in cloud applications •
5. CO5 Analyze emerging technologies in modern cloud computing

## FAQ

**How many units are in Cloud Computing?**

Cloud Computing (PEC321BCOM) has 5 units and 45 hours of theory: Unit I Introduction to Cloud Computing (9 h); Unit II Virtualization in Cloud Computing (9 h); Unit III Cloud Platforms and Applications (9 h); Unit IV Security in Cloud Computing (9 h); Unit V Modern Cloud Environment & Emerging Technologies (9 h).

**What is the marks scheme for Cloud Computing?**

The official Computer Engineering 2024 pattern syllabus lists continuous comprehensive evaluation (CCE) for 30 marks and the end-semester exam for 70 marks, for 3 credits.

**What should I know before Cloud Computing?**

Prerequisite listed in the syllabus: Computer Networks.
