UNIT I

Introduction

6 hours

Virtual Reality (VR): Introduction, Key Elements of VR, Experience, History, Applications. Augmented Reality (AR): Introduction, History, Key Aspects, and Applications.

UNIT II

Interface to the Virtual World

8 hours

Input: User Monitoring, Position Tracking, Body Tracking, Physical input Devices, Speech Recognition (Audio Input) and World Monitoring: Persistent Virtual Worlds, Bringing the Real World into the Virtual World. Output: Visual Displays: Properties of Visual Displays, Monitor-basedor Fishtank-VR, Projection-based VR, Head-based VR, See-through Head-based Displays, Handheld VR. Aural Displays: Properties of Aural Displays, Head-based Aural Displays- Headphones, Stationary Aural Displays-Speakers. Haptic Displays: Properties of Haptic Displays, Tactile Haptic Displays, End-effector Displays, Robotically Operated Shape Displays, Vestibular and Other Senses.

UNIT III

Representing and Rendering the Virtual World

8 hours

Representation of the Virtual World: Visual Representation in Virtual Reality, Aural Representation and Haptic Representation in Virtual Reality. Rendering Systems: Visual Rendering Systems: Visual Rendering Methods, Geometrically Based Rendering Systems, Non-geometric Rendering Systems, Rendering Complex Visual Scenes, Computer Graphics System Requirements. Aural Rendering Systems: Visual Rendering Methods, Rendering Complex Sounds, Sound- Generation Hardware, Internal Computer Representation. Haptic Rendering Systems : Haptic Rendering Methods, Rendering Complex Haptic Scenes with Force Displays, Haptic Rendering Techniques.

UNIT IV

Interacting with the Virtual World and Virtual Reality Experience

7 hours

User Interface Metaphors, Manipulating a Virtual World, Properties of Manipulation, Manipulation Operations, Navigating in a Virtual World-Way finding and Travelling, Classes of Travel Methods Interacting with Others-Shared Experience, Collaborative Interaction, Interacting with the VR System, Immersion, Rules of the Virtual World: Physics, Substance of the Virtual World.

UNIT V

Augmented Reality

6 hours

Concepts: Computer Graphics, Dimensionality, Depth Cues, Registration and Latency, Working of Augmented Reality, Augmented Reality Hardware (Sensors, Processors, Displays), Ingredients of an AR Experience. Augmented Reality (AR) and Virtual Reality (VR) headsets mainly find applications in gaming, movies, and other forms of entertainment. French

UNIT VI

Augmented Reality Software and Mobile Augmented Reality

7 hours

Augmented Reality Systems, Software Components, Software Tools for Content Creation, Interaction in Augmented Reality, Augmented Reality Techniques: Marker based and Marker less tracking, Mobile Augmented Reality.

Course outcomes

  1. CO1Understand the basics of Augmented and Virtual reality systems and list their applications
  2. CO2Describe interface to the Virtual World with the help of input and output devices
  3. CO3Explain representation and rendering system in the context of Virtual Reality
  4. CO4Analyze manipulation, navigation and interaction of elements in the virtual world
  5. CO5Summarize the basic concepts and hardware of Augmented Reality system
  6. CO6Create Mobile Augmented Reality using Augmented Reality techniques and software

FAQ

How many units are in Augmented and Virtual Reality?

Augmented and Virtual Reality (310254B) has 6 units: Unit I Introduction (6 h); Unit II Interface to the Virtual World (8 h); Unit III Representing and Rendering the Virtual World (8 h); Unit IV Interacting with the Virtual World and Virtual Reality Experience (7 h); Unit V Augmented Reality (6 h); Unit VI Augmented Reality Software and Mobile Augmented Reality (7 h).

What is the marks scheme for Augmented and Virtual Reality?

The official Computer Engineering 2019 pattern syllabus lists mid-semester (Mid-Sem) for 30 marks and the end-semester exam for 70 marks, for 3 credits.

What should I know before Augmented and Virtual Reality?

Prerequisite listed in the syllabus: Computer Graphics (210244).
