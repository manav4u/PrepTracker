## Course outcomes

1. CO1 Understand OOP concepts like classes, objects, inheritance, and polymorphism.
2. CO2 Use methods, constructors, and memory management.
3. CO3 Apply inheritance and polymorphism for code reuse.
4. CO4 Handle exceptions and use generics with collections.
5. CO5 Perform file handling and implement basic design patterns.

## FAQ

**How many units are in Object Oriented Programming?**

Object Oriented Programming (PCC-202-ITT) has 5 units: Unit I Foundations of Object-Oriented Programming (6 h); Unit II Methods and Constructors (6 h); Unit III Inheritance & Polymorphism (6 h); Unit IV Exception Handling and Generic Programming (6 h); Unit V File Handling and Design Patterns (6 h).

**What is the marks scheme for Object Oriented Programming?**

The official Information Technology 2024 pattern syllabus lists continuous comprehensive evaluation (CCE) for 30 marks and the end-semester exam for 70 marks, for 3 credits.

**What should I know before Object Oriented Programming?**

Prerequisite listed in the syllabus: Programming and Problem Solving.
