Course outcomes

  1. CO1Design responsive and accessible web pages using HTML5, CSS3, Bootstrap, and web standards.
  2. CO2Develop interactive client-side applications using JavaScript, JSON, AJAX, jQuery, and modern scripting techniques.
  3. CO3Build Single Page Applications (SPAs) using TypeScript and Angular framework.
  4. CO4Develop RESTful web services and full-stack web applications using Node.js, Express.js, and MongoDB.
  5. CO5Deploy, manage, and secure web applications using cloud services, version control tools, and DevOps practices.

FAQ

How many units are in Web Application Development?

Web Application Development (PEC-321C-IT) has 5 units and 45 hours of theory: Unit I Foundations of Web Technologies and Responsive Design (9 h); Unit II Client-Side Scripting and Interactive Web Applications (9 h); Unit III Front-End Frameworks and Single Page Applications (9 h); Unit IV Server-Side Development and Database Integration (9 h); Unit V Mobile Web Development, Cloud Deployment and Security (9 h).

What is the marks scheme for Web Application Development?

The official Information Technology 2024 pattern syllabus lists continuous comprehensive evaluation (CCE) for 30 marks and the end-semester exam for 70 marks, for 3 credits.

What should I know before Web Application Development?

Prerequisite listed in the syllabus: Programming Fundamentals, Database Management Systems, Computer Network.
