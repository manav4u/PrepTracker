UNIT I

PIC Architecture and Embedded C

7 hours

Comparison of CISC and RISC Architectures, Data and Program memory organization, Program Counters, Stack pointer, Bank Select Register, Status register, Embedded C concepts, Header and source files and pre-processor directives, Data types, data structures, Control loops, functions, bit operations.

UNIT II

Port and Timer 0 Programming

5 hours

I/O Ports and related SFRs, I/O port programming in C. PIC 18 Timer 0 Programing in C. Delay programming (with and without Timer0). LED Interfacing and its programming.

UNIT III

CCP Module and its applications

6 hours

CCP module in PIC 18 microcontroller, Timers required for CCP Applications, Applications of CCP mode Generation of Square waveform using Compare mode of CCP module. Period measurement of unknown signal using Capture mode in CCP module, Speed control of DC motor using PWM mode of CCP module.

UNIT IV

Interrupt structure and its Programming

5 hours

Interrupt Programming, Programming of Timer0 interrupts, Programming of External interrupts INT0.

UNIT V

ADC structure and LCD interfacing

7 hours

PIC ADC, Programming of ADC using interrupts, Measurement of temperature and Power. Using PIC microcontroller. Interfacing of LCD (16x2) in 4 bit mode.

UNIT VI

Serial Communication and its protocols

6 hours

06 Serial Communication structure and its programming (Data transmit and Receive), Introduction to Communication protocols as SPI and MODE BUS

Course outcomes

  1. CO1Explain architecture of PIC 18F458 microcontroller, its instructions and the addressing modes.
  2. CO2Use Ports and timers for peripheral interfacing and delay generation.
  3. CO3Interface special and generate events using CCP module.
  4. CO4Effectively use interrupt structure in internal and External interrupt mode.
  5. CO5Effectively use ADC for parameter measurement and also understand LCD interfacing.
  6. CO6Use Serial Communication and various serial communication protocols.

FAQ

How many units are in Advanced Microcontroller and Embedded System?

Advanced Microcontroller and Embedded System (303145A) has 6 units: Unit I PIC Architecture and Embedded C (7 h); Unit II Port and Timer 0 Programming (5 h); Unit III CCP Module and its applications (6 h); Unit IV Interrupt structure and its Programming (5 h); Unit V ADC structure and LCD interfacing (7 h); Unit VI Serial Communication and its protocols (6 h).

What is the marks scheme for Advanced Microcontroller and Embedded System?

The official Electrical Engineering 2019 pattern syllabus lists mid-semester (ISE) for 30 marks and the end-semester exam for 70 marks, for 3 credits.
