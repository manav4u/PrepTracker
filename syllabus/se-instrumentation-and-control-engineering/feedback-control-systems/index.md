## Course outcomes

1. CO1 Develop the mathematical model of control systems
2. CO2 Analyze the Time domain response of control systems and calculate time domain specifications of second order systems.
3. CO3 Analyze the system stability in time domain using Root Locus method.
4. CO4 Analyze the system stability in frequency domain using Bode plot and Polar plot method.
5. CO5 Evaluate the parameters of PID controller through Zeigler Nichols and Cohen Coon Tuning method to optimize system performance.

**How many units are in Feedback Control Systems?**
