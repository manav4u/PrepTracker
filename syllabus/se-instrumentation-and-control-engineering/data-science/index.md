## Course outcomes

1. CO1 Execute data collection and sampling methods to gather data for analysis effectively.
2. CO2 Implement statistical tools and techniques to analyze and interpret data accurately.
3. CO3 Use data science packages for data processing, analysis, and visualization efficiently.
4. CO4 Demonstrate proficiency in exploratory data analysis techniques and present insights effectively.

## FAQ

**How many units are in Data Science?**

Data Science (MDM-271-INC) has 4 units: Unit I Data Science (5 h); Unit II Data Science Packages (8 h); Unit III Exploratory Data Analysis (6 h); Unit IV Data Cleaning and Data Visualization (7 h).

**What is the marks scheme for Data Science?**

The official Instrumentation and Control Engineering 2024 pattern syllabus lists continuous comprehensive evaluation (CCE) for 30 marks and the end-semester exam for 70 marks, for 2 credits.
