## Course outcomes

1. CO1 Analyze and compare parallel and distributed database architectures, fragmentation s strategies, query processing, and concurrency control mechanisms.
2. CO2 Apply NoSQL database concepts and implement MongoDB-based solutions using CRUD operations and indexing techniques.
3. CO3 Model and manage complex and unstructured data using column-family, graph, and vector database technologies.
4. CO4 Design analytical data solutions using dimensional modeling, OLAP architectures, ETL processes, and cloud data warehousing platforms.
5. CO5 Evaluate streaming, time-series, and emerging database technologies for real-time analytics, IoT applications, and modern data-driven systems.

## FAQ

**How many units are in Advanced Database Management System?**

Advanced Database Management System (PEC-321B-IT) has 5 units and 45 hours of theory: Unit I Parallel & Distributed Databases (9 h); Unit II Introduction to NoSQL Database Systems and MongoDB (9 h); Unit III Advanced NoSQL Databases and Emerging Data Models (9 h); Unit IV Cloud Data Warehousing (9 h); Unit V Stream Processing, Time-Series, and Next-Gen Models (9 h).

**What is the marks scheme for Advanced Database Management System?**

The official Information Technology 2024 pattern syllabus lists continuous comprehensive evaluation (CCE) for 30 marks and the end-semester exam for 70 marks, for 3 credits.

**What should I know before Advanced Database Management System?**

Prerequisite listed in the syllabus: Basic of Database Management Systems (DBMS).
