## Course outcomes

1. CO1 Explain mobile computing concepts, mobile platforms, architectures, and application lifecycle models.
2. CO2 Apply principles of user interface and user experience design for mobile applications.
3. CO3 Explain and analyze mobile application components, navigation mechanisms, and event-driven programming models.
4. CO4 Explain data management techniques, web service integration, and cloud-based mobile application architectures.
5. CO5 Apply security, testing, optimization, and deployment concepts in mobile application development.

## FAQ

**How many units are in Mobile Application Development?**

Mobile Application Development (PEC-362C-IT) has 5 units and 45 hours of theory: Unit I Introduction to Mobile Computing and Android Platform (9 h); Unit II User Interface Design and User Experience (9 h); Unit III Mobile Application Components and Application Logic (9 h); Unit IV Data Management and Service Integration (9 h); Unit V Advanced Mobile Application Development (9 h).

**What is the marks scheme for Mobile Application Development?**

The official Information Technology 2024 pattern syllabus lists continuous comprehensive evaluation (CCE) for 30 marks and the end-semester exam for 70 marks, for 3 credits.

**What should I know before Mobile Application Development?**

Prerequisite listed in the syllabus: Object Oriented Programming,Database Management Systems.
