UNIT I

Introduction to RPA & Bot Development Basics

7 hours

Foundations of RPA: Emergence and definition of Robotic Process Automation (RPA), Benefits, Types of Bots (attended, unattended, hybrid), Application areas of RPA (finance, healthcare, HR, customer service), RPA development methodology and key considerations (process selection, security, governance), Overview of RPA tools (UiPath, Blue Prism, Automation Anywhere, Power Automate). Bot Development Fundamentals: Activities, Flowcharts and Sequences, Sequencing the workflow, Log Message (information, warning, error), Variables, Control flow, Various types of loops (For Each, While, Do While), Decision making with conditions, Best practices for Bot Development, Step-by-step example using Sequence and Flowchart, Step-by-step example using Sequence and Control flow.

UNIT II

Data Manipulation & Control Interaction

7 hours

Data Handling Techniques: Data table usage in RPA (build, add row, filter, sort, loop through rows), Clipboard management (copy to clipboard, get clipboard text), File operations (copy, move, delete, read, write text file), Data transfer between CSV/Excel and data table (read CSV, write CSV, read range, write range, append range). UI Control Automation: Finding the control (selectors, UI explorer), Techniques for waiting for a control (wait for ready, element exists, attribute equals), Act on controls – Mouse and keyboard activities (click, type into, hover, hotkeys), Handling events (click trigger, key trigger), Recording and scraping (basic recording, desktop recording, web recording, data scraping).

UNIT III

Handling User Events & Assistant Bots

7 hours

Assistant Bots and Event Monitoring: Assistant bots (concept, use cases, attended automation scenarios), Monitoring system event triggers (system idle, process started, window opened), Monitoring image and element triggers (image appears, element disappears, attribute changes). Keyboard Event Automation: Launching an assistant bot on a keyboard event (global hotkeys, shortcut keys), Practical examples (opening bot on Ctrl+Shift+B, triggering automation on function keys), Managing multiple keyboard triggers without conflicts.

UNIT IV

Exception Handling & Logging

7 hours

Exception Handling Strategies: Common exceptions in RPA (selector not found, timeout, application not responding, argument null), Strategies for exception handling (try-catch, throw, retry scope, continue on error), Using finally block for cleanup activities. Logging and Debugging Mechanisms: Logging mechanisms – Client logging (local log files, debug output), Server logging (Orchestrator logs, cloud logging), Taking screenshots for error debugging (capture screenshot on exception, save to log), Best practices for logging (log levels, message formatting, avoiding sensitive data).

UNIT V

Code Management & Contemporary Issues

7 hours

Code Organization and Maintenance: Project organization best practices (folders for workflows, libraries, and data files), Choosing between Flowcharts, State Machines, or Sequences, Maintaining and scaling RPA code (modular design, reusable libraries, version control). Current Trends and Future Directions: Security, Governance and compliance in RPA (role-based access, audit trails), Attended vs. unattended automation (differences and use cases), AI integration with RPA (Intelligent Process Automation, OCR), Future trends in industrial process automation using RPA (hyperautomation, cloud RPA).

Course outcomes

  1. CO1ANALYZE Robotic Process Automation technology, its value proposition, types of bots, application areas, and popular RPA tools.
  2. CO2DEMONSTRATE bot development using sequences, flowcharts, variables, control flow, loops, and decision-making constructs in an RPA platform like UiPath.
  3. CO3DIFFERENTIATE between various data manipulation techniques (data tables, file operations, CSV/Excel transfer) and UI control automation methods (recording, scraping, mouse, keyboard activities).
  4. CO4DESIGN automation solutions that handle user events through assistant bots, manage exceptions using try-catch and retry mechanisms, and implement logging with screenshots.
  5. CO5EVALUATE effective code organization, workflow structure selection, and contemporary RPA trends including security, governance, attended/unattended automation, and AI integration.

FAQ

How many units are in Robotic Process Automation?

Robotic Process Automation (PCC-352-RAI) has 5 units: Unit I Introduction to RPA & Bot Development Basics (7 h); Unit II Data Manipulation & Control Interaction (7 h); Unit III Handling User Events & Assistant Bots (7 h); Unit IV Exception Handling & Logging (7 h); Unit V Code Management & Contemporary Issues (7 h).

What is the marks scheme for Robotic Process Automation?

The official Robotics and Artificial Intelligence 2024 pattern syllabus lists continuous comprehensive evaluation (CCE) for 30 marks and the end-semester exam for 70 marks, for 3 credits.
